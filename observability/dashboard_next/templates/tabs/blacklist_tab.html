🚫 Manual Track Blacklist

Use this tab to blacklist tracks that are a wrong version (e.g. remix instead of original), corrupted or have audio issues, or otherwise unsuitable.

What happens when you blacklist a track: the username+file combination is added to the blacklist (if downloaded from Soulseek), the local file is deleted from disk, and the track's status is set to blacklisted so it's searched again in future search runs.
