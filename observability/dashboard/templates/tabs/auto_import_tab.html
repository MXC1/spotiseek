How to mount a directory in Docker

Add your music directory to the dashboard service's volumes in docker-compose.yml. On Windows, invoke up runs docker-compose inside WSL, so use the WSL-mounted-drive path (/mnt/<lowercase-drive-letter>/...) — a raw Windows path like E:/Folder breaks volume parsing:

  dashboard:
    volumes:
      # ... existing volumes ...
      - /mnt/e/Folder:/mnt/music:ro  # Mount your music folder

Then use /mnt/music as the path. Run invoke up after editing.
